## 📌 Overview
A lightweight, high-performance developer portfolio built with semantic HTML, modern CSS, and vanilla JavaScript. Deployed with continuous delivery on **AWS Amplify Hosting** and served globally via **Amazon CloudFront**.

---

## 🚀 The Creative Feature
* **MediaPipe ISL Gesture Sandbox & Simulator:** Interactive in-browser 21-landmark coordinate visualizer simulating real-time Indian Sign Language (ISL) gesture translation with zero camera latency.
* **Developer CLI Terminal:** An in-browser shell emulator supporting commands like `help`, `skills`, `projects`, and `telemetry`.
* **Global Command Palette:** Quick navigation triggered anytime via `⌘K` or `Ctrl+K`.

---

## ☁️ AWS Cloud Architecture
* **AWS Amplify Hosting:** Automated CI/CD pipeline linked to GitHub for zero-downtime atomic deployments.
* **Amazon CloudFront:** Global Content Delivery Network (CDN) ensuring sub-50ms latency worldwide.
* **Amazon S3:** Highly durable origin store for static assets.
* **AWS Certificate Manager (ACM):** Managed TLS/SSL certificates for secure HTTPS delivery.
